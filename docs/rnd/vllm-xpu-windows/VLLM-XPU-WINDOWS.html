2. The wall

Every intel/sycl-tla (CUTLASS-SYCL) kernel — flash attention, the MoE grouped GEMM, the gated-delta kernel — faults the device on Windows. Standalone, they return UR_RESULT_ERROR_DEVICE_LOST. In the engine, they return OUT_OF_RESOURCES surfacing at the next sync. This happens under drivers 8974 and 9030, JIT or AOT, on both 2026.0 and 2026.1 SYCL runtimes.

This is a compiler-line gap, not a capability gap. The B70 advertises every required extension on Windows (cl_intel_subgroup_2d_block_io, cl_intel_subgroup_matrix_multiply_accumulate, split barrier). Linux validates these kernels on IGC 2.11–2.38. The Windows driver ships an unpublished IGC line (clang-14 default, clang-16 fallback). No Linux-compiler codegen has yet run on this hardware.

6. Traps

  • A directory named vllm in the cwd shadows the package. Use vllm-src.
  • Deprecated api_server has a stray import uvloop. Use vllm serve.
  • A dead EngineCore leaves the API-server holding ZMQ :29550. Use kill-seat.ps1.
  • JSON in serve.cmd arguments splits on commas. Needs its own .cmd file.
  • The captured graph path warms over its first 2–3 runs. Sample three times.
  • An access violation in a Triton launch means the previous kernel faulted the GPU.
  • A killed -j16 ninja keeps compiling in the background. Check for live clang-cl.exe.
  • Bash heredocs mangle \v/\b/\w in Windows paths. Write patch scripts directly.
  • The toolkit's ocloc is Windows driver-lineage. AOT here does not test Linux IGC codegen. Read the dumped artifact's own markers before deciding AOT or JIT.
  • Sandbox guard trips on Remove-Item targeting the /Run string. Work around with [IO.File]::Delete and Start-Process schtasks.
  • Installer modals are readable via EnumWindows but UIPI prevents programmatic clicks. Human must click.
  • Build logs describe the build intent, not the installed binary. Verify compiled SPIR-V magic signatures.
  • Cross-boot comparison is needed before naming TPM events as a cause. They are an every-boot regime.

10. Today's side quests

The password scare post-reboot was not a temporary profile. A DPAPI master key access failed on the first boot (no record of key found), generating 839 errors. On the second boot, the credential key was found and re-keyed in place automatically (same GUID). Chrome and Edge data remained intact and no data was lost. The initial theory blaming TPM clearance was retracted after a cross-boot comparison proved TPM events happen on every boot — they are a regime, not a signal.

NPU driver 32.0.100.5540 installed successfully. Reopen test NPU-21 passed using both the PLUGIN and the now-usable DRIVER compiler types. Both 4778 and 5540 lower the 71-input expert graph to the identical 235 ops and identical 2030.80 µs estimate (vs the 1.50 ms gate), so the family stays closed. The Gemma embedding fix in this driver un-parks the LZ-card NPU embedder seat.

Platform Performance Package 26.08.100.3 installed, blocking for 17 minutes on an OEM policy modal. The modal was readable via EnumWindows but UIPI prevents programmatic clicks, so it required Derek to click OK. The driver became active without a reboot, and IPF updated correctly. A reboot remains optional.
