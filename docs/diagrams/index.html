01 · Component Topology (Architecture)

HEARTH Sovereign Control Plane

Physical 3-node cluster topology on the local network. Separates the FastMCP perimeter and NATS JetStream dispatch from physical GPU compute rungs, governed by the Rung Scheduler (ADR-0031) and Anti-Drift Guard (ADR-0003).

hearth-control-plane.html Architecture · Deployment-Ownership Profile · Trace Motion
Open Standalone ↗ JSON Spec Contact Sheet
🛡️ Fail-Closed MCP Perimeter (ADR-0021)
All external callers (Claude Code, Gemini, local CLI) enter through the FastMCP door on port 8710. Discovery mirrors authorization: unclassified tools raise at boot and close the door.
⚡ GPU Leaves the Control Plane (ADR-0036)
Inference happens on physical Arc hardware (A770 16GB, A580 8GB, B580 12GB). Control loops never block on Vulkan execution; dispatches ride NATS JetStream with explicit acks.
🔒 Anti-Drift State Invariants (ADR-0003)
The Anti-Drift Guard continuously reconciles in-memory agent state against immutable on-disk fixtures. Any detected state drift halts execution immediately.

⏱️ Non-Scalar Rate Throttles (ADR-0044)
Rate limits are not simple counters; budget holds throttle token velocity before hardware limits trigger memory faults, holding runs in a paused but recoverable state.
👤 Commander Intent Frontier (ADR-0012)
Major architectural moves pause for Commander review at the frontier lane without abandoning the execution context or losing trace correlation.
🔄 Hardware Rung Swap
If OMEN's Arc B580 experiences out-of-memory or driver stalls, the scheduler automatically swaps execution to AM4's 16GB Arc A770 and resumes the task graph.

05 · Governance

Architectural Decision Records (ADRs)

HEARTH architecture is governed by 63 formal ADRs. Key decisions referenced in the diagrams above:

ADR ID Title Architectural Principle
ADR-0003 Anti-Drift Disk Fixtures In-memory working state must reconcile against immutable disk fixtures every cycle. State drift fails closed immediately.
ADR-0010 Two Ledgers, Two Contexts Operational telemetry and career proof remain separated bounded contexts with one-way projections.
ADR-0011 Record-Event Double-Write Tool execution and ledger commitment occur synchronously before the result is delivered to the caller.
ADR-0012 Commander Intent Frontier Human intervention pauses execution at the frontier without tearing down execution state or losing OTel trace correlation.
ADR-0014 Machine Lanes Off Tailnet Internal M2M lanes use LAN / mshome addresses; Tailscale is strictly reserved for human access and the public Funnel proxy.
ADR-0021 Fail-Closed Routing Unclassified tools raise at startup. A gateway that only half-knows its security policy stays shut.
ADR-0031 Pin Chooses a Rung Pinning selects a hardware rung but cannot waive memory arithmetic. Over-budget prompts are rejected at the door.
ADR-0036 GPU Leaves Control Plane Physical GPU execution is an external compute resource accessed via durable messaging, never bound inside the orchestrator.
ADR-0044 Rate is Not a Scalar Token rates are velocity vectors across GPU memory thresholds, driving proactive backpressure rather than reactive recovery.
