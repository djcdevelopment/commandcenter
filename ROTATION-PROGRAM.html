The commodity question — "where should this request execute" — is adopted from existing infrastructure. The HEARTH question — "given backlog, quality beliefs, residency cost, KV state, thermals, and media contention, what topology should the box run next epoch" — has no open-source peer and stays ours. Plan of record: Derek-ratified 2026-08-28; pool changes in ADR-0039; lifecycle adoption pending ADR-0040 (probe-gated).

The FF layer changes the unit deliberately: every card above it measures throughput, none measures work. A configuration can win every tok/s row and still lose the factory — by rebuilding context four times, burning a window on re-prefill, or occupying both cards to produce one merged change. FF does not re-run the throughput sweep: corpus/schema/bench-row.v1.json already normalizes nearly every configuration axis, so FF supplies the missing numerator (work + quality), the occupancy vector, and the join — not another grid. FF1 is the campaign gate: if the work slice will not replay within a bounded CV, every card that divides by it is unanswerable and the layer stops there.

Constitution (standing constraints — do not re-litigate)

  • ADR-0008 advisory-first: the scheduler proposes; actuation needs a Derek-ratified ADR-0016-class decision plus a real regret trend. Shadow modes log divergence and dispatch the static choice.
  • Two economies: no metered/frontier tokens when a local placement is feasible; the CP-SAT objective already encodes this.
  • Single writer: every new evidence stream (rotation receipts, shadow logs, probe results) goes through the kernel/ledger paths; knowledge/*.json writes stay guard-enforced.
  • Evidence before belief: catalog values (omen_catalog.json) come only from measured receipts — the telemetry contract's nullable fields stay null until a measurement fills them.
  • Thermal ceiling: card 0000:04:00.0 runs 8–10 °C hot; 96 °C aborts; context depths 131072/262144 are quarantined on dual-split. The hot card gets the lighter model.
  • Loud fallbacks: a dark rung refuses loudly; maintenance windows are announced, never silent. A verdict never observed firing correctly is a hypothesis.
