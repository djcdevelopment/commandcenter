Findings along the way

#Finding
F1COOPMAT un-retired — the ADR-021-era GGML_VK_DISABLE_COOPMAT=1 TDR defense cost 2× prompt processing on driver 8974 (720 → 1451/1474 pp tok/s), zero TDRs on retest. Default flipped to ON in the harness preamble; Stage 3's soak is the extended trial.
F2The commit thief — OllamaBoot's serve (silently CPU-only since the 5070 left) held two resident model runners (17.4 + 48 GB private) from the boot sentinel probe onward: commit 92.1% with 75 GB physical free. Mechnet VMs were the visible suspect; the door's own default rung was the actual occupant. Stopped + disabled (elevated one-shot, ADR-0032 pattern). Ruling (Derek, Phase R): OllamaBoot STAYS disabled — its lifetime ledger reads net negative; pins require a deliberate start.
F3Poisoned-load demonstration (live, unplanned) — the first Stage 2 dual-70B bench loaded while commit sat at 92%: pp1024 = 11.8 tok/s vs the ≥150 floor (0.08×). Killing the co-tenant afterward did NOT recover it — placement decided at load time is permanent for the process. On the old 32 GB box this failure killed runs; on 128 GB it merely degrades silently — which makes the pre-load admission probe (DXGI budget + commit headroom) MORE load-bearing, not less. Adopted as a campaign convention: probe before every model load. Evidence: results\stage2-bench70b-*-POISONED-cotenant-load.jsonl. This is denning H1 reproduced on the new platform in the first two hours.
F4Commit, not free RAM, is still the wall (old L2, re-confirmed on 128 GB) — watchdog rule switched from percent (90%) to headroom (< 6 GB available commit) so honest no-mmap 70B loads don't false-abort.
F5The observer killed the experiment — an msys tail -f on the soak's summary log intermittently held it without write-share; the driver's log write threw at 23:04 and the first soak launch died while its bench ran on healthily. Fixes: logging made weaker than the experiment (retry ×3 → console-only, never throw), and log readers use Get-Content -Wait (full share). The 2026-06 telemetry-disagreement lesson has a sibling: instrument-vs-experiment interference is a real failure class on Windows file semantics.
F7VRAM grazed the ceiling: 94 °C peak on one card (abort line = 95), the other 86 °C — an 8 °C card-to-card delta under identical load is the airflow diagnostic Derek predicted. GPU cores stayed ≤81 °C. Before Stage 7/8 escalate: case fan curve / card spacing review, or the finale trips the watchdog. The hotter card is at PCI 04:00.0. Ambient note (Derek, 2026-08-21): sustained load is heat-soaking the whole office — walls, desk. Room ambient is now a rising variable under the overnight numbers, and relocation to another room is on the table; the always-on rung makes this a permanent ~28 W idle / ~350 W loaded space heater.
F9THE KNEE IS SOLVED — it's a compile-time constant (post-campaign, 2026-08-22). The discriminating experiment (dense 14B, ONE card, single-tenant, same ladder geometry) produced the identical cliff: 134 tok/s @ np=8 → 27 @ np=10, p95 9→70 s (−80%, worse than the MoE). Third configuration, same knee → not bandwidth, not host, not model. Root cause found in ggml-vulkan source: static constexpr uint32_t mul_mat_vec_max_cols = 8 — decode batches ≤8 ride the fast mul_mat_vec kernel; 9+ fall to the general matmul path (the 10→12 uptick, 27→35, is that path slowly scaling — the path-switch signature). denning's N* = min(N*_bw, capacity_limit) was right: the binding branch is capacity_limit, and it's this constant. Testable prediction: recompile with 16 → knee moves to 16. Rung's -np 4 / admission-8 now kernel-grounded. (Caveat: constant read from the older on-disk source checkout; b10549 behavior matches.)
F6Deep-context pp needs a time model — pp49152 on the 70B ≈ 25 min/double-rep (the 60-min leg cap killed a healthy run mid-test; peaks that window: GPU 79 °C, VRAM 86 °C, watchdog clean). Stage 3 restructured: r=1 at ≥32k depth, -n 0 (tg comes from Stage 4 servers), caps sized from the measured 4k–32k curve (346→110 pp tok/s). Bench legs are now resumable (stable filenames + skip-if-complete), so a killed night re-launches without re-spending finished legs.
